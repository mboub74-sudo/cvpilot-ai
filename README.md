# CVPilot AI

Bilingual resume editor MVP (English/Français), keyword-based job description review, and PDF/DOCX exports.

## Getting started

```bash
npm install
npm run dev
```

Build: `npm run build` (Vite). Deploy `dist/` to Vercel.

**Status:** Demo MVP only. AI writing is not connected. Keyword overlap is not an ATS certification or job-prediction score. Resume data is saved locally in the browser; do not enter sensitive information on shared devices. PDF export is best for Latin characters.

The app is independently authored; check package licenses before commercial deployment.
